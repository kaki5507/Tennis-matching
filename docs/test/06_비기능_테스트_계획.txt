 06. 비기능 테스트 계획

[성능]  도구: Lighthouse(모바일), Vercel Analytics/Speed Insights, 브라우저 Network 탭
 NFT-001 [중] 메인 페이지 LCP 2.5초 이하, CLS 0.1 이하 (모바일 4G 시뮬레이션)
 NFT-002 [중] 목록 화면(매칭/대회) 첫 응답 2초 이내, 데이터 100건 기준
 NFT-003 [중] 관리자 대시보드: 요청 6개 이상이 병렬로 나가므로 전체 로딩 3초 이내 확인
              (통계 쿼리는 page_views 가 쌓일수록 느려짐 -> 인덱스 활용 확인: EXPLAIN)
 NFT-004 [중] page_views 10만 행/매칭 1만 행 시드 후 getVisitStats/getMatchTimeStats/
              getMatchTrend 응답 시간 측정 (각 1초 이내 목표, 초과 시 인덱스/캐시)
 NFT-005 [중] 레이아웃의 점검 상태 조회가 모든 요청에서 DB를 두들기지 않는지 확인
              (30초 캐시: 1분 동안 DB 조회 수 확인)
 NFT-006 [하] 간이 부하: 동시 50명이 목록/상세 조회 시 오류율 1% 미만 (k6 또는 autocannon)
 NFT-007 [중] Vercel Hobby 한도 점검: 함수 실행 시간(10초), 월 호출량, 크론 3시간 간격 동작

[호환성 / 반응형]
 NFT-010 [상] 모바일 폭 360/390/430px: 가로 스크롤 없음, 버튼 터치 영역 충분, 헤더 메뉴 동작
 NFT-011 [중] 태블릿 768px, PC 1280px 이상 레이아웃 정상
 NFT-012 [상] iOS Safari, Android Chrome, Samsung Internet, PC Chrome/Edge/Safari 최신 2개 버전
 NFT-013 [중] 다크모드/시스템 글자 크기 확대 시 레이아웃 유지
 NFT-014 [하] 관리자 히트맵/추이 차트: 모바일에서 가로 스크롤로 확인 가능

[접근성]
 NFT-020 [중] 키보드만으로 가입/방 생성 가능(Tab 순서, 포커스 표시)
 NFT-021 [하] 이미지/아이콘 대체 텍스트, 마스코트 role/aria-label
 NFT-022 [하] 색 대비(본문 4.5:1) - Lighthouse Accessibility 점수 90 이상

[신뢰성 / 장애 대응]
 NFT-030 [상] DB 연결 불가(Supabase 일시정지) 시: 사이트가 흰 화면이 아니라 오류 안내를 보이는지,
              점검 상태 조회는 fail-open 인지 확인
 NFT-031 [상] 점검 모드 켠 채 관리자 로그인/해제 가능 (잠김 방지) - E2E-006
 NFT-032 [중] 외부 서비스 실패 시 본 기능 유지: 푸시 실패해도 수락 처리 성공,
              감사 로그 기록 실패해도 본 작업 성공, 부천 사이트 조회 실패해도 크론이 죽지 않음
 NFT-033 [중] 동시성: 같은 방에 두 사용자가 동시에 신청, 방장이 동시에 수락/거절 -> 중복 행/잘못된 상태 없음
 NFT-034 [중] 재제출: 평가를 빠르게 두 번 제출해도 중복 행 없이 upsert, 점수 이중 반영 없음
              (평가 점수 누적이 upsert 와 별개로 이중 가산되는지 확인 - 점검 포인트)
 NFT-035 [중] 마이그레이션 롤백 계획: 빌드 중 migrate deploy 실패 시 이전 배포 유지 확인

[운영 / 관측성]
 NFT-040 [중] 서버 로그에 개인정보(이메일, ciDi, 토큰)가 출력되지 않음
 NFT-041 [중] 에러 발생 시 확인 가능한 경로: Vercel Logs, 감사 로그, (선택) Sentry 도입 검토
 NFT-042 [중] 백업: Supabase 자동 백업 범위 확인(무료 티어 한계), 중요 시점 수동 덤프
 NFT-043 [하] 크론 실행 이력/실패 알림 확인 방법 문서화

[데이터 일관성]
